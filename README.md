# 기사 프로젝트 노트

기사 프로젝트를 정리하는 한 장짜리 노트 페이지입니다. HTML 파일 하나(`project-note.html`)로 되어 있고, 별도 설치 없이 브라우저에서 열면 바로 쓸 수 있습니다. 휴대폰 화면에서도 볼 수 있게 만들었습니다.

## 구성

| 칸 | 설명 |
|---|---|
| 프로젝트 | 프로젝트를 한 줄로 적는 칸 |
| 주제 | 대주제만 표시 (현재: 경제) |
| 할 일 | 체크리스트 5개 |
| 날짜별 기록 | 11/18부터 하루 한 줄씩 기록, 버튼으로 날짜 줄 추가 |

개인정보(전화번호, 주소 등)를 입력하는 칸은 없습니다.

## 사용 방법

1. 저장소를 내려받거나 `project-note.html` 파일만 받습니다.
2. 파일을 브라우저에서 엽니다.
3. 각 칸을 눌러 바로 입력합니다. 할 일은 왼쪽 네모를 눌러 체크합니다.
4. 날짜별 기록은 "+ 오늘 기록 추가" 버튼으로 오늘 날짜 줄을 더합니다.

## 저장 방식

입력한 내용은 사용 중인 브라우저의 `localStorage`에 저장됩니다. 서버로 전송되지 않으며, 브라우저 기록을 지우거나 다른 기기에서 열면 보이지 않습니다.

## 디자인

- 크림색 바탕에 코랄, 앰버, 틸, 보라 포인트
- 천천히 움직이는 은은한 색 덩어리 배경 (움직임 줄이기 설정을 켜면 멈춤)
- 제목은 Noto Serif KR, 본문은 Noto Sans KR (Google Fonts)
